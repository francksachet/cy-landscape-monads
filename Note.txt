Les deux fichiers remplacent tes anciens CY_Landscape_Explorer.ipynb et notebook_landscape.py.
Ce qui a changé. La deuxième cellule de code contient maintenant une variable MODE :

python

MODE = "load"   # "load" : charger un results.json existant (rapide)
                # "scan" : relancer le scan complet dans le notebook (lent)

RESULTS_JSON_PATH = "output_optimized/results.json"   # si MODE="load"

CICYLIST_PATH = "cicylist.txt"    # si MODE="scan"
MAX_PS = 5
N_RANDOM = 150
SEED = 42

En MODE = "load", la cellule suivante ouvre directement le JSON produit par main_optimized.py (ou n'importe quel autre scan), affiche un résumé (nombre de CICYs, fibrés stables, paramètres utilisés), et passe directement à la visualisation — quasi instantané.
En MODE = "scan", le comportement est celui d'avant : le pipeline complet tourne dans le notebook, étage par étage, avec impression de la progression. À la fin, les résultats sont automatiquement sauvegardés dans output_notebook/results.json, pour pouvoir les recharger plus tard en MODE = "load" sans tout relancer.
Toutes les cellules de visualisation qui suivent (diagramme de Hodge, statistiques, fiches candidats, spectre) sont inchangées dans leur logique — elles consomment simplement la variable stable_results, peu importe d'où elle vient.
Pour ton usage concret : après ton scan main_optimized.py, mets RESULTS_JSON_PATH = "output_optimized/results.json", exécute tout le notebook — les graphiques apparaîtront en quelques secondes plutôt qu'en plusieurs heures.
